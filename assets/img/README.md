# B2 Motorsports image library

Generated for the standalone B2 Motorsports website. Every photo has a full (max 1600px wide, JPEG q78 + WebP q72) and a small (800px wide, JPEG q75) variant, filenames `<name>.jpg`, `<name>.webp`, `<name>-800.jpg`. The logo is PNG only, with a 400px-wide copy. `og-default.jpg` is a 1200x630 cover crop of the hero photo for social/link previews.

This file and `manifest.json` are for choosing photos and are never published: the build leaves every `.json` and `.md` file under `assets/` out of `dist/` and fails if one gets there (`tools/check-assets.mjs`).
